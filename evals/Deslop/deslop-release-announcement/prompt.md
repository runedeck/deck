# Introducing fluxcache 1.0

We're excited to announce fluxcache 1.0, a semantic cache for LLM API calls that understands prompt meaning, not just exact matches.

This release marks a major milestone: we've added a sidecar service mode alongside our existing Python library, making it easy to cache across multiple applications and languages. In our benchmarks, fluxcache reduced model API calls by 40%, with a median lookup time of just 120 milliseconds.

This release wouldn't have been possible without our community. We're grateful to the 14 contributors who sent pull requests, shaped our roadmap, and helped us build a tool that makes LLM applications faster and more cost-effective.

Whether you're running a single service or orchestrating microservices, fluxcache 1.0 is ready to optimize your LLM infrastructure.
