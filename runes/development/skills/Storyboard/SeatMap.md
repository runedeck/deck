# Seat map

Before an adversarial or research fan-out. Source: the angles, tracks, or reviewers the skill will spawn, with the model class of each and the rule that keeps them disjoint.

```text
 <subject>   <n> seats · no shared context · <method: refute | gather>
 ┌───────────────┐ ┌───────────────┐ ┌───────────────┐
 │ facts         │ │ logic         │ │ reception     │
 │ review class  │ │ review class  │ │ review class  │
 │ hits → quote  │ │ hits → quote  │ │ hits → quote  │
 └───────┬───────┘ └───────┬───────┘ └───────┬───────┘
         └─────────────────┴─────────────────┘
                           ▼
              settle: fixed | rejected with reason
 confirm · edit a seat · stop
```

Rules for the fill:

- Each seat names what it owns and what it must not cover when tracks are disjoint.
- The verifier or settler under the join uses a different model class from the seats when the skill requires independence.
- After the run, replace the third line of each seat with its count: hits, rows, or "failed".
