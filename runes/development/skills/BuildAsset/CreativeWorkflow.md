# Human direction workflow

Use this workflow for every creative round, including refinement and combination rounds.

## Prepare the round

1. Read the current asset brief, critique, and direction decision.
2. Separate invariants from open choices.
3. Assign each reference one role. Do not let a technical guide become style authority.
4. Define a bounded candidate count and meaningful variation axes.
5. Select a medium-appropriate presentation method before generation.
6. Give creative workers only the references and write access required for raw outputs.

A round brief records:

```text
Round:
Human director:
Asset medium:
Use context:
Preserve:
Change:
Explore:
Reference roles:
Prohibited content:
Candidate count:
Output boundary:
Presentation method:
```

## Generate candidates

1. Generate independent outputs with stable candidate identifiers.
2. Preserve raw bytes and worker provenance.
3. Record every worker attempt, including timeouts, refusals, partial outputs, and malformed outputs.
4. Do not let workers edit earlier candidates or operational files.
5. Do not replace an output because it looks weak. Weak outputs still belong to the round.
6. Stop when each declared attempt has an output or a recorded failure.

## Present the direction board

Present all accessible outputs through one medium-appropriate comparison. Show a safe failure card for each inaccessible output.

Use contact sheets for still images. Use synchronized loops for motion. Use level-matched playlists for audio.

Use specimen pages for fonts. Use turntables for models. Use representative contexts when isolated media hides important differences.

Create one presentation record for each output or failure card. Use candidate identifier or generation order for neutral ordering.

Present raw outputs before normalized or delivery evidence. Never state that the human reviewed content that the board could not present.

Do not use status colors, pass rates, leaderboards, hidden diagnostics, or machine-selected primary sections. These signals bias creative judgment.

Ask for critique in the human's vocabulary:

- Which candidate should form the basis of the next round?
- What must remain unchanged?
- What should come from another candidate?
- What feels wrong in identity, structure, timing, rhythm, tone, weight, readability, or style?
- Which directions should not return?

## Record direction

Convert the response into a direction decision. Preserve uncertainty and alternatives. Do not convert silence into acceptance.

```text
Basis:
Preserve:
Combine from:
Change:
Reject:
Open question:
Human wording:
```

If the feedback can change the perceived result, stop and use it for a new round. If the human selects a direction for technical admission, record that selection and continue with the technical workflow.

## Near misses

A request for conversion, encoding, subsetting, compression, or inspection is technical-only work when it makes no perceptible change. Approval state does not alter this boundary.

Route provenance-only requests to the project provenance audit process.

A request to create one disposable asset with no iterative review can use direct generation. Use this workflow for refinement, integration, delivery, or approval.
