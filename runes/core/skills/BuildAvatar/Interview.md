# The avatar interview

The question bank for BuildAvatar. Target 20 to 30 questions across five to eight rounds of the `AskUserQuestion` tool, at most four questions per round. A short confirmation pass is not an interview.

## Method

- Pre-fill every option you can infer from the session, the machine, and existing memory files. An inference becomes a confirmation question, never a silent fact.
- Keep `Other` open on every question; users answer fastest when the likely answer is one click and the correction is one sentence.
- Invite a provider memory export early: "In claude.ai Settings, Memory, ask: export everything in your memory about me, verbatim. Paste the result into any answer." One paste can fill three sections.
- Push back on a vague answer with one concrete follow-up. Record hedges as the user states them.
- Summarize each round in one sentence before the next.

## Rounds

### 1. Profile

- Confirm the inferred one-line profile (name, role, employer or venture, seniority, timezone).
- Which parts need editing: role wording, ecosystem description, location, languages?
- Which languages belong in the profile?
- PII default for third-party providers: full detail or anonymous?

### 2. Preferences

- What annoys you most in AI output? (verbosity and padding, sycophancy, unverified claims, jargon and slop)
- What do the best responses do that most do not? (lead with the answer, show evidence, take a position, do the work unprompted)
- Default response length when unspecified?
- One example each of a response that was exactly right and one that annoyed you.

### 3. Work

- Which current work belongs in the dated work section?
- What is each project heading toward? (personal infrastructure, open-source product, research playground, company potential)
- How much employer detail belongs in a cross-provider identity file?
- Do side ventures get a work section, a profile mention, or nothing?

### 4. Topics and hobbies

- Which standing topics should every AI tool track?
- Which of those are hobbies to keep distinct from work topics?
- Which topics are off limits?

### 5. Boundaries

- What may no AI tool store or repeat, ever? Offer categories (employer-confidential, family, health and finances, security posture) and accept a general principle instead.

### 6. Decisions

- What convinces you, in order of trust? (measured data, working demo, first principles, prior art)
- When is "measure first" the wrong instinct?
- Tooling risk appetite? (early adopter with exits, boring base, by layer)
- How do you learn something new? (read source, docs, build a probe, talk it through)

### 7. Collaboration

- What may agents do without asking? Name the hard limits with each grant.
- How should agents pace long autonomous work? (run to completion, milestone checkpoints, confirm at forks)
- When should agents push a notification?
- How many parallel agent sessions is a normal state?
- Which hours are your working window, if any?

### 8. Goals and beliefs

- Which goals should agents keep in view over the next 12 months?
- Which technical beliefs are standing assumptions?
- What should agents actively challenge you on?

## After the rounds

Read every `Other` and note field before you compose; users put the richest material there, including whole memory exports. Map each answer to its file section. Anything still blank after two asks becomes an open item in the report, not a third ask.
