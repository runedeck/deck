    How to read this report

    The benchmark asks one question: does the artifact change model behavior enough to earn its context cost? Each model ran the same tasks twice. Only the artifact differs between the two runs.

    The grader

    A deterministic script, not a model. It reads each response and checks every frozen fact check. Each check names one required fact, figure, or restriction. The result is pass or fail, with evidence.

    The checker

    A deterministic program that scans the response for rule violations. One violation is one finding. This benchmark uses the checker named under Identities. It counts Simplified Technical English violations, for example a passive sentence or a banned word. Findings for each 100 words makes short and long responses comparable.

    The blind judge

    A language model from a different vendor than the model under test. It reads both responses with shuffled A and B labels. It never learns which response used the artifact. It picks a winner for each judging dimension and gives one reason.

    Assertion pass rate (0–1, higher is better). The case assertions measure required behavior. A drop means the artifact harmed a requirement.

    Checker findings (per 100 words, lower is better). The report divides total findings by total words across matched outputs.

    Clarity (0–1, higher favors the artifact). A blind judge selects the output with less ambiguity.

    Fluency (0–1, higher favors the artifact). A blind judge selects the more natural output.

    Directness (0–1, higher favors the artifact). A blind judge selects the output that states useful information sooner.

    Verdict rule: Required meaning must not regress. Checker findings must decrease. Every enabled preference dimension must meet its threshold. A lower score produces a trade-off verdict. The report never averages models.

    Verdict settings

    The aggregate stores the recorded verdict. A manifest can set a weight and thresholds for each judge dimension.

    Review the pairs

    Each pair shows one task and one model, once with the artifact and once without it. The blind judgment for the pair appears below the texts.
