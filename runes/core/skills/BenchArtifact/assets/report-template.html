    How to read this report

    The benchmark asks one question: does an artifact change model behavior enough to earn its context cost? Each model ran the same tasks in every named arm. Only the treatment artifact differs between compared arms.

    Assertion pass rate (0–1, higher is better). The case assertions measure required behavior. A drop means the artifact harmed a requirement.

    Checker findings (per 100 words, lower is better). The report divides total findings by total words across matched outputs.

    Clarity (0–1, higher favors the artifact). A blind judge selects the output with less ambiguity.

    Fluency (0–1, higher favors the artifact). A blind judge selects the more natural output.

    Directness (0–1, higher favors the artifact). A blind judge selects the output that states useful information sooner.

    Verdict rule: required meaning must not regress. Checker, clarity, or directness gains can support a positive result. Lower fluency creates a trade-off, not an automatic failure. The report never averages models.

    Review the pairs

    Every matched pair shows the same task answered by the same model with and without the artifact, beside the blind judgment for that pair.
