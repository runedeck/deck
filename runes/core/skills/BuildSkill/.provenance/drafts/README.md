# Drafting evidence

Council proposals that informed the maintainer's block verdicts for this adoption, sealed with the review record by the signed commit. Each file name carries the first 16 hex digits of its SHA-256.

- `codex-gpt-5.6-sol-*` — codex harness, model gpt-5.6-sol, reasoning effort high; brief plus full-tree recommendations
- `grok-brief-N` / `grok-output-N` — grok harness, three batches (SKILL.md + workflow companions; topic companions; agent prompts + schemas)

These are maintainer-declared drafting evidence present at seal time. Digests are host-computed; the files prove what proposals were available, not model authorship or per-verdict causality. Retrospectively captured during the ceremony (the review began before this directory existed); verdict notes name which proposals the maintainer accepted, adapted, or overrode.
