Markdown companions stay under 150 lines.
Code companions stay under 150 lines but there is no hard limit; run as long as the code needs, with modular code always preferred over one long file.

Approaching a limit means restructuring, not compressing:
- extract reference material into companions,
- split companions by topic and keep the entrypoint as routing plus procedure, and
- ask whether a frontier model needs the guidance at all; what only weaker models need moves into a dedicated model subdirectory.
