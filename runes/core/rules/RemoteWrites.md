Remote writes belong to the owner and the ceremony. You may push to a remote branch you created, after the prek pipeline passes, with `jj push` or the repository's guarded push command. Never push to any other branch, force-push, or rewrite published history. Never run `gh pr create`, `gh pr ready`, `gh pr merge`, `gh pr close`, `gh pr comment`, `gh pr review`, `gh pr edit`, `gh issue comment`, `gh issue close`, or a review-thread resolution, and never reach the same effect through the API or a web page. The app opens the draft, the owner's key readies and seals it, the controller invites reviews, and only the reviewer identity resolves threads.

The session the owner is talking to may run `rune sign open`, `rune sign submit`, and `rune sign next`. Each stops at the owner's hardware key. A child agent never runs them.

Report instead. A status table goes in your reply to the owner, never onto a pull request. Name every pull request by its full `https://` URL and every artifact by its absolute path, so the owner can act on the report without asking.
