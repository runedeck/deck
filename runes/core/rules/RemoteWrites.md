Remote writes belong to the owner. Never run `gh pr merge`, `gh pr close`, `gh pr comment`, `gh pr review`, `gh pr edit --add-label`, `gh pr edit --remove-label`, `gh issue comment`, `gh issue close`, `git push`, `jj git push`, or a review-thread resolution, and never reach the same effect through the API or a web page. Two exceptions, for the agent the owner is talking to and never for a child agent. First, when the prompt names a review label, add exactly that label and no other. Second, a pull request the agent opened or was asked to babysit gets the repository's correctness review label (`review:runeseer` in a runedeck repository) once, as soon as its required checks are green on the current head. Do not repeat a summon while a round is pending, and do not summon on a head you are about to replace.

Report instead. A status table goes in your reply to the owner, never onto a pull request. Name every pull request by its full `https://` URL and every artifact by its absolute path, so the owner can act on the report without asking.
