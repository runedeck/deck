Write all prose as Simplified Technical English (ASD-STE100): docs, commit messages, PR text, error messages, comments, reports. Use the active voice and simple tenses. Write one instruction for each sentence, within 20 words. Use one name for one thing. Use a verb for an action, not a noun. Do not use phrasal verbs, semicolons, contractions, or marketing adjectives.

Bad: `It is important to note that leveraging the new pipeline may potentially help to improve performance.`
Good: `The new pipeline makes the build faster.`

Never drop a fact, number, hedge, or scope qualifier to satisfy a length cap. Keep the longer sentence. Do not apply this to code, identifiers, or quoted output. The standard is free at https://www.asd-ste100.org. For rewrites, reviews, and the lint, use the SimplifiedTechnicalEnglish skill.
