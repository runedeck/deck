Delete a user file or directory with `trash <path...>`, never with `rm`. The command is `scripts/trash` in every runedeck repository and `~/.local/bin/trash` on the owner's machines, the same script. On macOS it hands the item to `/usr/bin/trash`, which moves it to the Trash that Finder shows. The owner sees it there, can put it back, and frees its space by emptying the Trash. On Linux it uses `gio trash`, or the FreeDesktop trash under `~/.local/share/Trash` when `gio` is missing. A sandboxed command can trash when the sandbox may write `~/.Trash`.

`rm` stays for scratch and regenerable content only: a `mktemp` directory, a cargo `target/` directory, `build/` output, a cache. Before you trash a workspace or a checkout, remove its build directories with `rm`. Trashed build output fills the disk until the owner empties the Trash. A path that this session did not create, or that cannot be regenerated, goes to the trash.

Recover an item on macOS with Finder's Put Back, or move it out of `~/.Trash`. On Linux, move it back from `~/.local/share/Trash/files/<name>`. The original path is in `~/.local/share/Trash/info/<name>.trashinfo`.
