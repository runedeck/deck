Give every task that you delegate a limit and a stop condition. A child agent cannot see what the work is worth, and it can repeat one step for hours while you wait.

Write the limit into the brief: the inputs to read, the most tool calls or minutes the task may use, and the shape of the report. Base the limit on a similar task that finished, and add a margin. Do not ask for every file in a directory when a few files answer the question. LimitImageReads sets the limits for images.

Tell the child to stop and report when it reaches the limit. Tell it also to stop when it calls the same tool with the same input a third time. A partial report that names the cause is a good result.

When the child returns, compare its tool calls and time with the limit. Report an overrun to the user with the numbers. Change the brief before you delegate the task again.
