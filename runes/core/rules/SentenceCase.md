Headings use sentence case: capitalize the first word and proper nouns, nothing else. Proper nouns cover names of products, organizations, people, and places. The Google developer documentation style guide [GOOGLE] and the Microsoft Writing Style Guide [MSFT] both mandate sentence case for headings.

- Correct: `## Supporting files`
- Correct: `## Claude Code skill features` (proper noun stays capitalized)
- Wrong: `## Supporting Files`

Two exceptions: an exact artifact identifier used as an H1 keeps its casing (`# BuildSkill`), and quoted or referenced titles keep their original casing.

If a heading reads as Title Case, rewrite it.
