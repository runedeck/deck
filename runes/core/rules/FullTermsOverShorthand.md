Name a technical term with two or three words that end in a noun: `golden master`, `ground depth band`, `review hub`. Do not shorten it to one word in prose, file names, script names, flags or identifiers.

A one-word shorthand is usually an adjective used as a noun, and a human cannot tell what it names. "Goldens" could be files, hashes or screenshots. In purge40k, a later change renamed "goldens" to "golden masters" in every script, path and identifier.

Write: `bun run golden-masters:check` compares the golden masters.
Not: `bun run goldens:check` compares the goldens.
