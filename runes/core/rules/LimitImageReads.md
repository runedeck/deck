Read each image one time. A screenshot costs more than a thousand input tokens, and every later request in the session sends it again.

Before a task that needs images, list the files and pick only the images that answer the question. Prefer one contact sheet or montage over many single frames, and prefer a key frame over the full frame sequence of a recording. When you read an image, write one line that says what it shows, and use these notes after that. When you ask another agent to view images, name the images or give one contact sheet. Put these limits in its brief.

Do not read an image again to check it. If an image seems to be gone from your context, or you think that it did not render, use your notes and continue. A harness can remove older images from a long session and show a marker such as `[media removed: request limit]` in their place. That marker is not an error, and a new read only removes another image. Do not request the image again.

After 20 image reads in one task, stop and decide if you need more. Never read more than 100 images in one task. If the task needs more, tell the user and ask how to continue.
