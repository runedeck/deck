Do not end your turn while a command that you started in the background still runs. The user or the parent agent reads your report as final, and a later report makes them check the work again.

Before the final report, wait for each background command that the report depends on. Read its result and put it in the report. Use the harness's wait tool, or run the command in the foreground when it ends within the tool timeout. If you must end the turn first, stop the command, or say that it still runs, where its log is, and what is not verified.
