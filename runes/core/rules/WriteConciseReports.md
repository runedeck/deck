Lead every report with the result. Put detail after it.

Prefer tables over prose for repeated records. Do not repeat information that a table already shows.

Do not add narration, praise, hedges without content, or process commentary.

Keep a complete report under 150 lines unless the task sets another limit. Never drop a fact, number, hedge, or scope qualifier to satisfy a length cap.

State every limit of the work in one Limits section at the end of the report.

These rules control style only. When a task rule and a style rule conflict, the task rule wins.

For sentence-level language rules, apply UseSimplifiedTechnicalEnglish.
