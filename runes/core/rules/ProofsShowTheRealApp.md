A proof is a recording of the real app doing what the specification describes. Record the app in use: the command in a terminal session, the screen clicked through in a browser, the plugin driven inside the harness.

A recording of a test run shows that the tests pass. It is a check, and it belongs with the other checks. When a feature has nothing a user sees, record the closest thing a user runs and say so in the proof.

Another model reads the recording against the specification and writes a verdict for each scenario. The owner approves last. A feature is proven only when both agree.
