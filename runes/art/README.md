# art

`Art` coordinates visual reference research, painting plans, and art collection maintenance.
It distinguishes artwork, painted objects, renders, and partial references.

`PaletteCritic` is its independent review agent. It checks proposed colors, material behavior, values, contrast, and practical constraints.
The agent returns findings. Art resolves those findings and owns the final guide or collection update.

Deploy the skill and agent together through the module. A skill-only selection does not deploy the separate agent.
Providers without named agents can receive the canonical agent instructions through an available task tool.
Without delegation, Art labels its review as self-review.

Technique companions cover Speedpaint, fluorescent ink, OSL, and NMM.
Collection companions preserve attribution, evidence categories, Obsidian validation, and the local logging standard.
They load only for the corresponding work.

The shared `Obsidian` skill owns vault placement, note identity, frontmatter cleanup, migration, and layered application validation.
Deploy the `obsidian` module with Art when collection work needs that workflow.
Art retains image categories, source evidence, painting methods, and PaletteCritic responsibilities.
