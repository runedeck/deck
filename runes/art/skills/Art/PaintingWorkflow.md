# Painting workflow

Use this procedure for physical painting guides and material-dependent palette choices.
For a digital palette, review visible color roles without imposing physical paint or miniature preparation rules.

## Recover the painting brief

1. Identify the subject, variant, target image, and intentional departures from it.
2. Recover the actual paint inventory, including metallics, inks, medium, and opaque preparation materials.
3. Identify the current surface state: bare, primed, shaded, drybrushed, highlighted, or already colored.
4. Recover brush or airbrush access, desired effort, finish, and base treatment.
5. Apply the current bottle limit. Do not turn an earlier five-color preference into a permanent rule.

Use a supplied inventory or existing note before suggesting purchases.
Do not demand that the user list bottles already recorded in the conversation or collection.

## Build the plan

Map the reference into large color groups, secondary materials, small accents, and the base.
Inspect neighboring values as well as hue. Dark cloth can disappear against dark flesh even when their paint names differ.
Use the strongest contrast to support the intended focal point.
Treat a contrasting base as an intentional design choice when the user requested one.

Select the application method before specifying dilution.
Distinguish a flowing coat, a controlled glaze, an opaque correction, drybrushing, and an airbrush tint.
Broad smooth wings and textured scales need different paint handling.
Retain usable existing preparation. Transparent paint depends on the values beneath it.

For Speedpaint, fluorescent ink, OSL, and NMM, follow the technique companion supplied by Art.
Preserve the user's fluorescent inks and their choice of actual metallics or NMM.
An available metallic collection does not settle which metal method the user wants.

Each chosen paint needs a visible purpose and compatible method.
Count each distinct colored bottle used in mixtures. Count the ground unless the brief excludes it.
State whether medium, opaque preparation, rim paint, or fluorescent materials are excluded by the user.
If the plan exceeds the budget, simplify the mapping or state the conflict before adding more colors.

## Verify the important claims

Use manufacturer application examples and original demonstrations for paint behavior.
Inspect the shown preparation, formulation, loading, and application method.
Do not infer opacity, fluorescence, exact hue, or suitability from a bottle name.
Do not attribute a photographed miniature's recipe to its painter without their documented process.

State whether tutorial evidence came from footage, selected frames, captions, or written steps.
Record only the ratios and timing supported by the source or the user's test.
Proposed mixtures need named components, their intended effect, and a small test on matching preparation.

## Review and return

Give PaletteCritic the proposed mapping, preparation, method, constraints, and evidence through Art's handoff procedure.
The agent checks the proposal. The coordinator resolves findings and writes the guide.
Do not replace the whole palette when a small supported correction solves the problem.

Use a compact result:

```text
Palette: paint and target area.
Preparation: what must exist before the color layer.
Order: practical sequence and handling for each surface.
Reference: source links and limits on the proposed color match.
Test: only the unresolved material check that can change the plan.
```

A paint-to-area table can help the user compare several miniatures.
An immediate guide can use verified collection references while broader art research continues separately.
