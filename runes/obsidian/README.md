# obsidian

`Obsidian` organizes notes through human-readable folders and meaningful relationships.
It inspects the current vault before it proposes a destination or changes a link.
It verifies saved content, exact link destinations, and affected views separately.

The skill uses the target vault's conventions and supported dedicated CLI.
It has no fixed vault path, folder tree, required hierarchy property, or automatic linking service.
Fixtures support workflow review without touching a live vault.

Art retains visual reference classification, painting methods, and PaletteCritic review.
Art uses this module for reusable Obsidian organization and validation.
Deploy both modules when that integration is required.
This source change does not install either module or authorize a vault migration.
