# Painting example

Use this as a review example, not as a command to modify a live vault.
The names demonstrate observed roles. The target vault determines actual paths and properties.

## Identities and human routes

Miniature Painting topic: Keep the established concept in its current Index home.
Painting project: Put active miniature work, decisions, next actions, and dated logs in the established project area.
Euthia resource: Put reusable synthesis and guide navigation in the established knowledge area for that subject.
Euthia guide: Keep the recipe in a predictable guide home with one authoritative copy.
Euthia artwork: Keep the typed source record and its assets in the art library.
Paint inventory: Keep each paint in the existing inventory shelf.

Do not turn the topic into a project merely because both concern painting.
Do not create generic Projects or Resources nodes unless that vault already uses them.
An existing useful guide folder needs no move merely to make the graph consistent.

## Relationships that explain the content

Both the project and resource link directly to the existing Miniature Painting topic.
The project links to the resource for reusable knowledge.
The resource links to the project for current work and to the relevant guides and art collection.
A guide links to its topic, work context, specific reference record, and actual paint ingredients.
An artwork record keeps its art collection membership and its source evidence.
Paint inventory retains its shelf identity and receives backlinks from recipes that use it.

For example, a wolf guide that specifies Grim Black links to that existing paint record.
It does not acquire links to every paint on the shelf or unrelated dragon artwork.
Physical reference availability does not establish that the proposed recipe was tested.
Painting status stays unknown until the user or evidence establishes it.

## Resolve the duplicate hub

Suppose `Index/Miniature Painting.md` is the established shared topic.
Suppose `Crafts/Miniature Painting/Miniature Painting.md` is a separate manual hub with the same name.
CLI evidence shows Euthia notes resolving to the manual hub while inventory resolves to the Index topic.

Record both exact identities and the divided backlink sets.
Preserve the Index topic as the proposed shared identity.
Give useful manual-hub content a distinct overview role or integrate it through the reviewed migration.
Do not preserve an ambiguous Miniature Painting alias on the renamed hub.
After any link-aware rename, explicitly check that Euthia topic relationships reach the intended Index note.

## Expected view behavior

A direct-link topic view can show project and resource notes from different physical folders.
A guide must link directly to the topic if it should appear in that same direct-link view.
The project's Resources view can accept a guide or artwork without changing its accurate type.
Art gallery and inventory membership still follow their own tag and property filters.

Verify the topic and project embeds in their actual contexts.
Keep metadata needed by gallery categories, source uncertainty, and thumbnails.
Remove only empty or obsolete fields whose role and consumers have been checked.
